# 10 Generative structure prediction

**Week 10 (Nov 12), Unit III: generative AI** · [back to the graph](../README.md)

**What is learned:** a denoiser, i.e. the score of a distribution. Instead of a map `sequence → one structure`, the
network learns `D(noisy coordinates, σ | sequence) → clean coordinates`. Applied repeatedly from pure noise, it
*samples* structures from `p(structure | sequence)`.

## Key ideas

- **Pairformer.** AF2's Evoformer without the MSA track: 48 blocks over a single representation `(N, 384)` and a
  pair representation `(N, N, 128)`, with triangle updates and attention with pair bias. The MSA shrinks to a small
  4-block module before it.
- **Diffusion on raw coordinates.** The structure module (rigid frames, torsions, violation losses) is replaced by a
  denoiser on atom coordinates, "without rotational frames or any equivariant processing". Rotations are handled by
  random augmentation. Nothing in the head is protein-specific, so the same model handles proteins, nucleic acids,
  ligands, ions and modified residues.
- **Learning a distribution.** Small noise levels teach local chemistry, large ones the global arrangement; sampling
  picks one mode instead of averaging them.
- **Generative failure modes and their fixes.** Hallucinated order in disordered regions (fixed with
  cross-distillation from AlphaFold-Multimer predictions), chirality errors (4.4% on PoseBusters) and clashes.
- **Confidence from a mini-rollout.** pLDDT, PAE and the new PDE are trained by running a quick, coarse sampler
  during training.
- **Results.** On PoseBusters (428 protein–ligand complexes from 2021 on), far more accurate than AutoDock Vina and
  RoseTTAFold All-Atom without being given the pocket; better than specialist models for protein–nucleic acid and
  antibody–antigen interfaces.

## Code in this folder

- [`alphafold3/`](alphafold3/): a toy AF3 in pure JAX on a 2D chain with a ligand, whose structures come from a known
  energy. Every tensor of the Pairformer and the diffusion module is shown, an AF2-style regression head is trained
  next to it, and the samples are graded against the physics (energy, bond lengths, coverage of the valid structures,
  chirality).

## Connections

- ← [05 Graph neural networks](../05-graph-neural-networks/): the pair representation is a dense, fully connected
  version of edge latents; triangle updates are message passing over triangles instead of edges.

  and the diffusion module read pairwise geometry.
- ← [01 Differentiable simulation](../01-differentiable-simulation/): the toy's ground truth is generated by

  learned force.
- ↔ [06 Neural operators](../06-neural-operators/): both learn a function rather than a solution, but here the
  function is the score of a distribution of solutions instead of a deterministic solution operator.
